## 关闭 Modern UI（推荐）

Modern UI 会把侧边栏、底部面板改成浮动卡片（圆角 + 间隙），并替换标题栏、标签页等一整套样式。

`zhouhe-dark` 的配色是按**经典布局**调的，开启 Modern UI 后，外壳区域会走 VS Code 的默认回退色，容易出现"外壳颜色和编辑器背景打架"的情况。

点下面的链接定位到开关，把它设为 `false`：

[打开 Modern UI 设置](command:workbench.action.openSettings?%5B%22workbench.experimental.modernUI%22%5D)

> 这是实验性设置，只有较新的 VS Code 才有这一项。老版本里搜不到的话，跳过这一步即可。
